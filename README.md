# 🧲 Ultra-Realistic Magnets: Iron Filings & Physics Simulation

A high-performance, interactive physics simulation that visualizes magnetic fields using iron filings and rigid-body magnet dynamics. Built with Vanilla JavaScript and Canvas API.

![Magnet Simulation Preview](https://via.placeholder.com/800x450/050505/00f2ff?text=Ultra-Realistic+Magnets+Simulation)

## 🌟 Features

- **Dynamic Magnetic Fields**: Real-time visualization of magnetic field lines using thousands of "iron filings" that react to magnet positions and orientations.
- **Rigid-Body Physics**: Magnets feature mass, velocity, friction, and angular momentum.
- **Collision Dynamics**: Realistic collisions between magnets with spark effects and impulse response.
- **Interactive HUD**: Control the simulation state and view instructions through a sleek, cyberpunk-inspired UI.
- **Mouse Magnetism**: Toggle your cursor to act as a magnetic pole, influencing both filings and magnets.
- **Custom Scaling**: Resize magnets on the fly to change their strength and physical properties.

## 🎮 Controls

| Action | Control |
| :--- | :--- |
| **Move Magnet** | Left-Click and Drag |
| **Rotate Magnet** | Right-Click and Hold |
| **Scale Magnet** | Mouse Wheel (over magnet) |
| **Toggle Mouse Magnet** | Click "Mouse As Magnet" in HUD |

## 🚀 Technical Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Graphics**: HTML5 Canvas API for high-frequency particle rendering.
- **Physics**: Custom-built Euler integration engine for linear and angular motion.
- **Styling**: Cyberpunk aesthetic with frosted glass effects (backdrop-filter) and CSS variables.
